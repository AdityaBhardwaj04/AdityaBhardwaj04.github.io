# BLACKBOX

> **A self-updating cybersecurity portfolio that evolves with my journey.**

BLACKBOX started with a simple question:

> **Why do portfolios become outdated?**

As cybersecurity professionals and developers, we constantly solve machines, publish projects, earn certifications, contribute to GitHub, and learn new technologies.

Ironically, the one place that's supposed to showcase all of that—our portfolio—is often the last thing we update.

Not because we don't care.

Because we're busy building.

I wanted my portfolio to reflect what I'm doing **today**, not what I was doing months ago.

That idea became **BLACKBOX Sentinel**.

Instead of manually updating my portfolio every time I solve a Hack The Box machine or push a project, Sentinel automatically gathers my latest activity, detects meaningful changes, regenerates the portfolio data, and republishes the website.

The result is a portfolio that continuously evolves alongside my learning.

# The Philosophy

A portfolio shouldn't be another project that needs maintenance.

It should be a living representation of your journey.

BLACKBOX treats the portfolio like a production system.

Instead of hardcoding achievements and manually editing content, automation keeps everything synchronized.

The frontend remains completely static.

The data doesn't.

# BLACKBOX Sentinel

Sentinel is the automation engine behind BLACKBOX.

It runs independently through GitHub Actions every six hours and performs all data collection before deployment.

Every execution:

- Fetches my latest GitHub activity
- Retrieves Hack The Box profile information
- Tracks recent HTB machine activity
- Collects badges and machine statistics
- Detects changes since the previous execution
- Generates telemetry
- Updates the activity timeline
- Writes fresh JSON data
- Republishes the portfolio only when something actually changed

The frontend never communicates directly with GitHub or Hack The Box.

Instead, it simply reads static JSON files generated by Sentinel.

This keeps the website:

- Fast
- Secure
- Static
- Cache-friendly
- Independent of third-party APIs during page load

# Deployment

BLACKBOX uses two independent GitHub Actions workflows.

### Deploy

Runs whenever code is pushed to `main`.

- Install dependencies
- Build the application
- Upload GitHub Pages artifact
- Deploy

### Sentinel

Runs automatically every six hours.

If Sentinel detects meaningful activity since the previous execution, it updates the portfolio data and commits the changes.

That commit automatically triggers a new deployment.
